bluedoc 1.2 is about the home page. The more docs you kept, the longer it took to come back after a restart, because the server read every doc before it drew the first row. Now it reads a small index instead.

## It opens at once

Each doc's summary lives in a SQLite index beside your answers, `index-<schema>.db` next to `state.db`, and it survives restarts. On a 224-doc home the first rows now take 5 ms after a restart, down from 3.3 s.

The index keeps itself current in the background. A new or changed doc shows up within a second. Checking that a doc still builds, which is what puts the "doesn't build" badge on a card, runs in a low-priority worker process, and no page waits on it. While the index fills for the first time, the home says "indexing N of M"; `serve.py status` shows the same progress.

## Scroll, search, Statistics

The home loads 25 rows or 48 cards at a time as you scroll. Date groups carry on across batches with their full counts, and Back or a reload keeps your place.

Search runs on the server, over the full text of every doc, and each hit comes with a snippet of where it matched. The page no longer downloads the whole search data up front.

Cards draw their hero from a template per doc type and a few numbers. A doc, design or deck card no longer draws the doc's own canvas or board, which is much of why the home is fast.

## Upgrades don't break anything

Your picks, ticks, comments and approvals stay as they were; the index builds itself the first time 1.2 starts. An older agent's `serve.py open` no longer replaces a newer server that's already running, and a bump that only changes the version doesn't restart it. Tabs you opened on 1.1 keep working until you reload, and a doc page opened after the update says "bluedoc was updated · Reload".

To update in Claude Code, run `claude plugin marketplace update bluedoc`, then `claude plugin update bluedoc@bluedoc`; the README's [Update and remove](https://github.com/andreiverdes/bluedoc#update-and-remove) table has the commands for every other agent. Everything that came before is in the bluedoc 1.1 release notes.
